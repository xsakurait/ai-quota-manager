# 基本設計書 共通項目

本ファイルは基本設計・詳細設計・画面設計・API設計で共通に参照する項目を集約する。各設計書は値を複写せず、本ファイルを参照する。

## C-1 用語
| 用語 | 定義 |
|---|---|
| サービス定義 | 無料枠を持つサービス1件の定義（ID・名称・種別・上限・単位・リセット周期・備考） |
| 使用量 | 利用者が記録した消費量。サービスIDをキーに保持する |
| 残量 | 上限から使用量を引いた値（0未満にはならない） |
| 状態 | 使用率から判定する 通常 / 注意 / 枯渇 |

## C-2 単一の情報源
- サービス定義・上限・単位・リセット周期・状態閾値・状態ラベル・種別ラベル・周期ラベル・保存キー・環境変数名は、すべて `src/shared/config/catalog.ts` のみに定義する。
- 画面・feature・APIはいかなる上限値・閾値のリテラルも持たない。

## C-3 状態判定（概念）
- 状態は使用率（使用量 ÷ 上限）に対する共通閾値で判定する。閾値の具体値は C-2 の単一情報源を参照する（本書では複写しない）。
- 判定順序: 枯渇閾値以上 → 枯渇、注意閾値以上 → 注意、それ以外 → 通常。

## C-4 リセット周期の種類
daily（日次）/ weekly（週次・月曜起算）/ monthly（月次・月初）/ 5hour（5時間枠）。ラベルは C-2 を参照する。

## C-5 保存方式
- 使用量はブラウザ localStorage に保存する。保存キーは C-2 を参照する。DBは使用しない。
- 保存形式は「サービスID → 使用量（数値）」のJSONオブジェクトとする。

## C-6 エラー方針（API共通）
- 入力検証エラーは 400、存在しないリソースは 404、想定外エラーは 500 とし、レスポンス形式は API設計書で定義する共通形式に従う。

## C-7 環境変数
- 環境変数名は C-2 の単一情報源で管理し、`.env.sample` にプレースホルダのみを記載する。秘密情報はコードに含めない。
