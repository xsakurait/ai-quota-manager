# 画面設計書

共通項目は `00_common.md` を参照する。本書では閾値・上限などの値を複写しない。

## 1. 画面一覧
| 画面ID | 画面名 | パス | 概要 |
|---|---|---|---|
| S1 | ダッシュボード | `/` | 全サービスの無料枠を一覧表示し、使用量記録と絞り込みを行う |

## 2. S1 ダッシュボード レイアウト
```
+--------------------------------------------------------------+
| ヘッダ: アプリ名 / サマリ（件数・合計使用量・枯渇件数）      |
+--------------------------------------------------------------+
| 検索入力 [________]  種別フィルタ [すべて|動画生成|ローカル] |
+--------------------------------------------------------------+
| サービスカード（サービスごとに繰り返し）                     |
|  名称 / 種別バッジ / 状態バッジ                              |
|  上限 / 使用量 / 残量 / 使用率                               |
|  次回リセット日時                                            |
|  使用量操作: [-] [数値入力] [+]                              |
+--------------------------------------------------------------+
```

## 3. 表示項目
| 項目 | 取得元 | 備考 |
|---|---|---|
| サービス名・種別・上限・単位・周期 | 共通設定（C-2） | ラベルも共通設定から取得 |
| 使用量 | localStorage（C-5） | 未記録の場合は 0 |
| 残量・使用率・状態 | 純粋ロジックで算出 | 判定基準は C-3 |
| 次回リセット | 純粋ロジックで算出 | 周期種別は C-4 |
| 状態バッジ | 状態に応じて色分け | 通常=secondary / 注意=default / 枯渇=destructive 相当 |

## 4. 操作仕様
- +/- ボタン: 使用量を1増減する。0未満・上限超過は共通ロジックでクランプする。
- 直接入力: 数値を入力すると即時に反映・保存する。不正な入力は 0 として扱う共通ロジックに従う。
- 検索: サービス名の部分一致（大文字小文字を区別しない）。
- 種別フィルタ: すべて / 動画生成 / ローカル。
- 絞り込み結果が0件の場合は「該当するサービスがありません」と表示する。
