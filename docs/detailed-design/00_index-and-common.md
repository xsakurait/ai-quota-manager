## 2. 共通項目（詳細設計）
基本設計の共通項目（`docs/basic-design/00_common.md`）を継承する。本ファイル群では値を複写しない。

### D-C1 命名・配置規約
- 純粋ロジックは `src/shared/lib/quota.ts` に集約し、副作用を持たせない。
- 共通設定は `src/shared/config/catalog.ts` のみ。環境変数の参照も同ファイルに集約し、未設定時は同ファイル内のフォールバック値を用いる。
- 型は `src/shared/types.ts` に集約する。

### D-C2 数値の扱い
- 使用量は有限な数値として扱い、NaN・無限大・負値は 0 に正規化する（詳細は 01）。
- 使用率は 0〜100 の整数（四捨五入）に丸める。

### D-C3 日時の扱い
- リセット計算はローカルタイム基準とし、基準時刻を引数で受け取る純粋関数とする（テスト容易性のため）。
- 表示は `toLocaleString` によるロケール形式とする。

### D-C4 テスト方針
- 詳細設計の各関数は単体テスト観点表（`docs/05_unit-test-viewpoints.md`）に対応する観点を持つ。
