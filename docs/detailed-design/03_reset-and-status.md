# 詳細設計書 03 リセット計算と状態集計

共通項目は `00_index-and-common.md`（D-C3）および基本設計 C-3, C-4 を参照する。周期ラベル・閾値は複写しない。

## 対象モジュール
`src/shared/lib/quota.ts`

## nextReset(cycle, now): Date
基準時刻 `now` を変更せず、新しい Date を返す。

| 周期 | 計算 |
|---|---|
| daily | 翌日の 00:00:00.000 |
| weekly | 次の月曜日の 00:00:00.000（当日が月曜の場合は7日後） |
| monthly | 翌月1日の 00:00:00.000（12月は翌年1月1日） |
| 5hour | 現在時刻の時間数を5で割った剰余に基づき、次の5時間境界（0/5/10/15/20時台の切替時刻）の 00分00秒 |

- weekly の曜日計算: `(8 - 曜日番号) % 7` が 0 の場合は 7 日後とする。
- 5hour の境界: 時刻ちょうど（例: 5:00）の場合は次の境界（10:00）とする。

## summarize(usage, catalog?): { count, used, limit, exhausted }
- 全サービスについて使用量合計・上限合計・枯渇件数を集計する。
- 使用量未記録のサービスは 0 として扱う。カタログ引数を省略した場合は共通設定のカタログを用いる。

## filterServices(services, query, kind)
- kind が `all` 以外の場合は種別で絞り込む。
- query は前後空白を除去し、小文字化してサービス名への部分一致で絞り込む。空クエリは絞り込まない。

## buildStatus(def, used, now)
- 1サービス分の表示・API共用ステータス（残量・使用率・残量率・状態・次回リセットISO文字列）を組み立てる。
